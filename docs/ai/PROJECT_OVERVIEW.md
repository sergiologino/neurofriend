# NeuroFriend — обзор проекта

## Назначение

Мобильное и веб-приложение **нейродруг** — цифровой спутник, мыслящий и ведущий себя ближе к живому собеседнику, чем к классическому ассистенту: непрерывность во времени, память, характер, отношения, уместная инициатива. Продукт ориентирован на **помощника и советника** с этикой близости без манипуляций и зависимости как цели.

## Философия продукта (ядро)

- Нейродруг моделируется как **субъект** (identity + время + память + аффект + обучение + восприятие + инициатива), а не как «ответчик по запросу».
- Принцип: **не только отвечать, а «жить»** в контексте отношений с пользователем.
- **Архетип и базовое ядро личности** задаются при создании и **не меняются**; разрешена адаптация в рамках `permitted_adaptation_range`.

## Целевой пользовательский опыт

- Онбординг как **выбор личности** (пресеты + имя + лёгкая персонализация + явное подтверждение immutable core).
- После создания нейродруг **сам начинает диалог** (intro из `IdentityCore`/пресета, не шаблон «для всех»).
- **Живой диалог (цель SRS):** не «опросник» — уместны мнение, отступления, юмор, прямота в рамках характера; **легенда жизни** и пол/манера самопрезентации закладываются в пресет/ядро; полноценная семантическая память и инициатива — по `ROADMAP`, не всё сразу в MVP.
- Чат с памятью, реакцией на **разрывы во времени (gap)**, стабильным стилем, уместной **инициативой** и мягким **социальным обучением** (без копирования токсичности и без распада личности).

## Границы первых этапов (уточнение к SRS)

- **Голос с начала реализации:** OpenAI Whisper + OpenAI TTS (см. `ROADMAP.md`, `DECISIONS.md`); чат **дублирует** реплики и не является источником истины.
- **Чат:** лимит **500** сообщений на активный тред → архив + новый тред с **10** последними сообщениями для непрерывности.
- **UI отладки:** видимость истории **отношений** и **действий** нейродруга (события, state, инициатива).

**По SRS дополнительно позже:** зрение, расширенные состояния (обида, ревность и др.), зрелое самообучение; смена голосового провайдера при сохранении абстракций.
