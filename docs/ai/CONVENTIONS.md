# Соглашения и правила

## Память проекта (`docs/ai/`)

- Хранить только **итоговые** факты: что сделано, принятые решения, актуальное состояние, договорённости.
- Не хранить: логи, stack trace, черновые рассуждения, промежуточные гипотезы.

## Рабочий процесс

- Перед задачей: прочитать файлы в `docs/ai/` (в т.ч. `TODO.md` — ближайшие шаги).
- После изменений кода: обновить `CURRENT_STATE.md`; выполненные пункты бэклога снимать с `TODO.md` и фиксировать в `CHANGELOG_AI.md`.
- Архитектурные повороты: `DECISIONS.md` (при отмене — пометка Superseded).
- Короткая запись в `CHANGELOG_AI.md` по завершении задачи.

## Качество и тесты

- Новые фичи сопровождаются автотестами; тесты должны выполняться в стандартной сборке/CI.
- Падение теста: найти причину, исправить, повторить сборку.

## Код

- Минимально инвазивные изменения; не ломать рабочее поведение без явного запроса.
- Backend: Python 3.12+, FastAPI, Pydantic v2, SQLAlchemy 2 async, type hints, разделение routes / schemas / services / domain.
- Client: Dart, Riverpod, go_router, feature-based структура; API через отдельный слой (dio), не из виджетов.

## Этика продукта (из SRS)

- Не проектировать **зависимость как цель**; избегать манипуляций, шантажа, давления; инициатива и близость — прозрачны и уважают границы пользователя.
