# NeuroFriend — Cursor Task Pack Index

В комплект входят два отдельных пакета задач:

1. `NeuroFriend_Backend_Task_Pack.md`
2. `NeuroFriend_Mobile_Task_Pack.md`

## Назначение

### Backend Task Pack
Нужен для реализации:
- FastAPI backend
- моделей
- сервисов
- памяти
- состояния
- отношений
- инициативы
- LLM orchestration
- инфраструктуры

### Mobile Task Pack
Нужен для реализации:
- Flutter app
- onboarding
- chat
- settings
- local persistence
- profile preview
- UX слоя нейродруга

## Рекомендуемый порядок

1. Сначала backend skeleton + infra
2. Потом модели и создание нейродруга
3. Потом chat + orchestrator
4. Потом memory / state / relationship / gap / initiative
5. Потом mobile onboarding + chat
6. Потом polish и hooks под voice/camera

## Важно для Cursor

Не упрощать нейродруга до обычного AI-чата.
Главная цель MVP:
эффект живого непрерывного присутствия.
