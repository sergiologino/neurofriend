# neurofriend_presets.json — комментарий

Главное дополнение в этой версии:
у каждого пресета добавлен блок `voice_style`.

Зачем он нужен:
- голос должен соответствовать архетипу личности;
- голос нельзя выбирать независимо от характера;
- backend/voice-layer должен использовать этот блок как ограничение при выборе TTS-голоса или voice profile.

Пример:
для пресета `home_quiet` специально запрещены впечатления вроде:
- мощный низкий сценический голос
- доминирующий голос
- радиоведущая подача

То есть пользователь, выбрав тихую домашнюю скромную девушку, не должен получить голос, который разрушает образ.

Рекомендуемое использование:
1. frontend использует JSON для UI галереи;
2. backend хранит canonical version;
3. voice service подбирает TTS/voice profile по `voice_style`;
4. personalization может чуть сдвигать параметры, но не ломать базовую совместимость голоса и личности.
