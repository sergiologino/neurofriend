# Инфраструктура (Docker)

## PostgreSQL

Для повседневной разработки **достаточно уже установленного локального PostgreSQL** на машине: задайте в корневом `.env` строку `DATABASE_URL` (см. `.env.example`) на ваш хост, порт, пользователя и базу. Отдельный контейнер Postgres **не обязателен**.

Сервис `postgres` в `docker-compose.yml` оставлен для окружений без локального инстанса (CI, другая машина) или для единообразного стека «всё в контейнерах».

## Остальное

Redis и Qdrant в compose при необходимости можно поднимать отдельно; backend корректно стартует и без них, если соответствующие функции ещё не используются (клиенты опциональны в коде).

Пример запуска только вспомогательных сервисов без контейнерного Postgres:

```bash
docker compose up -d redis qdrant
```

Backend при этом обычно запускают **на хосте** (`uvicorn` из `backend/`) с `.env`, указывающим на **локальный** PostgreSQL.
